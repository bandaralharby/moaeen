# مُعين المعلم

موقع تجريبي جاهز للنشر على Vercel أو Netlify.

## الملفات
- index.html: الواجهة الكاملة.
- vercel.json: إعداد بسيط لـ Vercel.
- netlify.toml: إعداد بسيط لـ Netlify.

## الخلفية
الواجهة متصلة مباشرة بـ Supabase Edge Function:
https://cixwjisioawswnnwwswf.supabase.co/functions/v1/moaeen-generate

بعد رفع المجلد كما هو، يعمل زر "إنشاء الملف" من الموقع المنشور.
